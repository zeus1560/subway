# 서울 지하철 혼잡도 분석 서비스

서울 지하철 이용자들이 실시간 혼잡도 정보를 확인하고, 최적의 경로와 탑승 칸을 선택할 수 있도록 돕는 웹 서비스입니다.

**🌐 [배포된 서비스 바로가기](https://station1-1dxwjl3n3-ahn-seungjoos-projects.vercel.app)**

---

## 문제 정의

### 사용자 페인 포인트

1. **혼잡도 정보 부재**: 출퇴근 시간대에 어떤 역이 혼잡한지, 어떤 칸이 여유로운지 알 수 없음
2. **비효율적인 경로 선택**: 시간만 고려한 경로 탐색으로 혼잡한 환승역을 지나가게 됨
3. **실시간 정보 부족**: 현재 시간대의 혼잡도는 알 수 있지만, 10분 후나 다른 시간대의 예상 혼잡도는 확인 불가

### 기술적 도전 과제

- 서울시 공공데이터 API의 제한적인 실시간성
- 대규모 지하철 네트워크(수백 개 역, 수십 개 노선)에서의 효율적인 경로 탐색
- 사용자 경험을 해치지 않는 빠른 응답 시간 확보

---

## 해결 방안

### 1. 데이터 기반 혼잡도 예측

- 서울시 공공데이터의 과거 승하차 데이터를 활용한 시간대별 혼잡도 패턴 분석
- 현재 시간과 사용자 설정 시간을 기반으로 한 예측 모델 구현
- 4단계 혼잡도 레벨(여유/보통/혼잡/매우 혼잡)로 직관적인 정보 제공

### 2. 혼잡도 기반 경로 탐색

- 다익스트라 알고리즘을 활용한 최적 경로 탐색
- 환승 횟수, 소요 시간, 혼잡도를 종합적으로 고려한 가중치 계산
- 여러 경로 옵션 제공으로 사용자 선택권 확보

### 3. 사용자 중심 UI/UX 설계

- 위치 기반 주변 역 자동 추천
- 즐겨찾기 및 자주 이용하는 경로 저장 기능
- 인터랙티브 노선도로 시각적 정보 제공
- 모바일과 데스크톱 모두에서 사용 가능한 반응형 디자인

## 핵심 기능

### 1. 실시간 혼잡도 조회
- 역별, 노선별 실시간 혼잡도 확인
- 시간대별 혼잡도 비교 (현재 vs 10분 후 예상)
- 열차 칸별 혼잡도 정보 (상행/하행 방향)

### 2. 경로 탐색 및 추천
- 출발역과 도착역 입력으로 최적 경로 탐색
- 혼잡도를 고려한 여러 경로 옵션 제공
- 환승 횟수, 소요 시간, 예상 혼잡도 정보 표시

### 3. 개인화 기능
- 위치 기반 주변 역 자동 추천
- 즐겨찾는 역 및 경로 저장
- 자주 이용하는 역 기반 개인화 대시보드

### 4. 시각화
- 인터랙티브 지하철 노선도 (줌, 팬, 역 선택)
- 혼잡도 색상 코딩으로 직관적인 정보 전달
- 노선별 필터링 및 역 검색 기능

### 5. 커뮤니티
- 역별 정보 공유 게시판
- 사용자 간 경로 및 혼잡도 정보 공유

## 기술 스택

### Frontend
- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **State Management**: React Hooks (useState, useEffect, useMemo, useCallback)
- **Charts**: Recharts
- **Icons**: Lucide React

### Backend
- **Runtime**: Node.js
- **API**: Next.js API Routes
- **Data Source**: 서울시 공공데이터 API (CardSubwayStatsNew)

### 알고리즘 및 데이터 처리
- **경로 탐색**: 다익스트라 알고리즘 기반 최단 경로 탐색
- **혼잡도 계산**: 승차 인원 기반 4단계 레벨 분류
- **예측 모델**: 시간대별 패턴 분석 기반 예측

## 설치 및 실행

### 필수 요구사항
- Node.js 18 이상
- npm 또는 yarn

### 설치

```bash
# 저장소 클론
git clone <repository-url>
cd station1

# 의존성 설치
npm install
```

### 환경 변수 설정

프로젝트 루트에 `.env.local` 파일을 생성하고 다음 내용을 추가하세요:

```bash
# 서울시 공공데이터 API 키 (필수)
NEXT_PUBLIC_SEOUL_API_KEY=your_seoul_api_key_here

# OpenAI API 키 (선택사항 - AI 기능 사용 시)
OPENAI_API_KEY=sk-your-api-key-here
```

**API 키 발급 방법:**
1. 서울시 공공데이터포털 (https://data.seoul.go.kr) 접속
2. 회원가입 및 로그인
3. "CardSubwayStatsNew" API 신청
4. 발급받은 API 키를 `.env.local` 파일에 입력

### 개발 서버 실행

```bash
npm run dev
```

브라우저에서 [http://localhost:4000](http://localhost:4000)을 열어 확인하세요.

### 프로덕션 빌드

```bash
npm run build
npm start
```

## 주요 페이지

- `/` - 메인 대시보드 (주변 역, 경로 찾기, 개인화 대시보드)

- `/board` - 커뮤니티 게시판
- `/favorites` - 즐겨찾는 역/경로
- `/settings` - 사용자 설정
